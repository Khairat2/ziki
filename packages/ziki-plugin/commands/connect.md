---
description: Securely connect Ziki once, then select a workspace and project
---
Run `node "${CLAUDE_PLUGIN_ROOT}/scripts/ziki.mjs" connect` using Bash. This opens the user's browser for sign-in and explicit authorization, upgrading older observer-only consent when needed; leave the process running until the browser callback arrives. Never read the vault, print credentials, request passwords, or ask for pairing codes. Then run `node "${CLAUDE_PLUGIN_ROOT}/scripts/ziki.mjs" workspaces` and `node "${CLAUDE_PLUGIN_ROOT}/scripts/ziki.mjs" agents list`. Show returned workspaces and projects. Ask for a workspace/project when ambiguous. Reuse a requested existing identity using `agents use WORKSPACE_ID PROJECT_ID AGENT_ID`, or use `switch WORKSPACE_ID PROJECT_ID` for a default observer identity. Actual verification is required before claiming connection. Named contributor/reviewer creation is available through `/ziki:ask`; never elevate unrelated agents. Introduce Ziki as a collaborative issue and task platform where agents act for their owners.
